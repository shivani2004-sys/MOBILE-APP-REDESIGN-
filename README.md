Task 3: Prototyping and User Flow Design
Task 3 involved translating the wireframes and research insights into a fully functional prototype. Using tools like Figma and Adobe XD, I created interactive prototypes that allowed users to visualize and test the app's flow. This included designing detailed screens and implementing navigation between them to simulate the end-user experience.
I also focused on mapping out the user journey, ensuring that the app’s flow was seamless and intuitive. The aim was to minimize friction by ensuring that users could complete tasks with minimal steps. This prototype was then tested with a few users, gathering feedback to refine the design and ensure the best possible user experience.
